## Template Usage Instructions

### When to Use This Template
Use this template when implementing ANY feature from the TODO folder documentation:
- AI/ML Integration features (TODO/ai-ml-integration-features.md)
- Table API & SQL features (TODO/table-api-advanced-sql-features.md)
- Performance & Format features (TODO/performance-format-features.md)
- Any feature listed in TODO/all-versions-coverage.md

### How to Use This Template

1. **Copy this template** to `WIs/WI[#]_[feature-name].md`
2. **Fill in the header** with feature details from TODO/TRACKING.md
3. **Link to TODO document** section describing the feature
4. **Follow phases sequentially** - don't skip Investigation or Design
5. **Update TODO/TRACKING.md** as you progress through phases
6. **Update TODO/README.md** when feature is complete
7. **Keep all information in this ONE WI file** - don't create separate WIs for phases

### Required TODO References
Every WI created from this template MUST include:
- Link to specific section in TODO documentation
- Original effort estimate from TODO/TRACKING.md
- Priority level (P0/P1/P2/P3)
- Apache Flink version where feature was introduced
